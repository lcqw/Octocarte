# Octocarte 0.0.6

Octocarte now connects to an existing Navidrome server. The standard Compose
installation starts only Octocarte and its supporting services; it does not
create or manage Navidrome.

- Keep Apple artist photos consistent after downloaded albums become local.
  Artists are matched using their name and album evidence; unrelated name-based
  biographies are omitted for matched Apple profiles.
- Include artist photos, Apple-ranked top songs and unattended service
  authentication in the installation.
- Provide the modified ALACarte source through its web UI and include licenses,
  notices and matching source archives with the release.
- Simplify the README and configuration examples for an existing Navidrome setup.

This is a regular release, without an alpha suffix. It targets Linux AMD64 and
Docker Compose v2 or newer. All five images use the immutable `0.0.6` tag.

## Installation and updates

For a fresh installation, follow the [quick start](../../README.md#quick-start).
Use the existing Navidrome address and the music path that server reads.

**Earlier installations that bundled Navidrome must not replace their Compose
file in place.** Follow the [migration guide](../MIGRATION.md) to preserve that
server, or remove the disposable old stack before using a separately managed
Navidrome installation. Music files are separate from Docker service-state volumes.

For an already standalone installation, follow [updating and backups](../OPERATIONS.md).
Set `OCTOCARTE_VERSION=0.0.6`, pull the images and recreate the services.

## Validation

The artist-profile change passed 702 .NET tests and the controlled HTTP playback,
range, album-submission and local-library handoff checks. Read-only checks using
live catalog and Navidrome records verified the NAV and Don Toliver photos.
The release workflow also tests installation against independently managed
Navidrome, persistence, ALACarte's source download, and pulled-back registry images.

Wavio, Aonsoku and Navic have been reported working with Octocarte. Compatibility
with every client feature or platform is not guaranteed. Apple catalog search is
currently added through `search3`; `search2` remains a Navidrome pass-through.

Source archives, image digests, Compose configuration and checksums accompany
this release. Existing ALACarte preferences remain under its control.
