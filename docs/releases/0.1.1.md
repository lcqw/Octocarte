# Octocarte 0.1.1

Fix downloads failing with `spawn apple-music-dl ENOENT` in 0.1.0.

The upstream downloader image changed to a binary requiring a musl loader that
was absent from its runtime image. Octocarte now pins the downloader base to the
exact digest used by the working 0.0.6 release. Both album and single-song modes
remain available, with full albums as the default.

Release verification now starts the actual downloader through ALACarte's launch
helper in both modes, using temporary staging directories with networking
blocked. The check runs during image builds and again after registry pulls.

## Updating

Update your checkout with `git pull --ff-only`, then set
`OCTOCARTE_VERSION=0.1.1` in your existing `.env`. Retain your chosen
`DOWNLOAD_WHOLE_ALBUM` setting and other configuration. Then run:

```sh
docker compose pull
docker compose up -d
```

Retry failed downloads after updating. Existing music and service state are
retained; Navidrome requires no change. The earlier 0.1.0 images remain immutable
but are superseded by this fix.

[Updating and backups](https://github.com/lcqw/Octocarte/blob/dev/docs/OPERATIONS.md)
